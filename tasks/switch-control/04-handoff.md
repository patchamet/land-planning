## การตัดสินใจสำคัญที่ทำไปแล้ว (อย่ารื้อโดยไม่มีเหตุผลใหม่)

| เรื่อง | สรุป | ทำไม |
|---|---|---|
| บอร์ด | **ESP32 Node-32S** (ไม่ใช่ 38 pin ของร้านเดียวกัน) | เป็นรุ่นเดียวที่ร้านระบุว่าเสียบ breadboard 830 ได้และพินเหลือ 2 ฝั่ง — รุ่น 38 พินไม่มี LED built-in และพิน 6–11 ติด SPI |
| ชิป | **ESP32 ไม่ใช่ ESP8266** | ESP8266 มี analog แค่ 1 ขา จะตันตอนต่อ soil moisture หลายจุดในเฟส sensor |
| relay | **กลไก 5V active-low** ไม่ใช่ SSR | โหลดบนโต๊ะเป็น DC (LED/ปั๊ม 5V) SSR ราคานี้ส่วนใหญ่สับได้แต่ AC · SSR น่ากลับมาดูตอนติดตั้งจริง |
| ไฟเลี้ยง relay | **5V จาก VIN** ไม่ใช่ 3.3V | คอยล์กินไฟ ดึงจากขา 3V3 เสี่ยง — และ active-low ทำให้ logic 3.3V สั่ง 5V module ได้อยู่แล้ว |
| ตารางเวลา | **เก็บใน ESP32 (NVS + NTP)** | คอม/broker ดับ สวิตช์ต้องยังทำงานตามเวลา (failsafe) |
| ร้าน | **AEI.th เป็นหลัก** IT-Garden สำรอง | ครบกว่า ถูกกว่า รีวิวเยอะกว่ามาก ส่งเร็วกว่า |

รายละเอียดของที่ตัดทิ้งไปแล้ว (พร้อมเหตุผล) อยู่ในตาราง "ตัวที่ดูแล้วตัดทิ้ง" ใน [03-procurement.md](03-procurement.md)

## ยังไม่ตัดสินใจ

- firmware เขียนด้วยอะไร (Arduino C++ / ESPHome / MicroPython) — ลองใน P1 แล้วค่อยเลือก
- หน้าเว็บควบคุมต่อกับ broker ยังไง (MQTT over WebSocket ตรงๆ หรือผ่าน script กลาง) — ตัดสินใน P3
