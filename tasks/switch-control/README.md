# Task: Switch Control — สวิตช์ไฟสั่งงานระยะไกล (เปิด/ปิด + ตั้งเวลา)

> สถานะ: 🟡 ร่าง
> แตกมาจาก: [docs/smartfarm/04-iot-architecture.md](../../docs/smartfarm/04-iot-architecture.md) — ดึงเฉพาะ **Control Node + เฟส D5** มาทำก่อน โดยยังไม่แตะฝั่ง sensor เลย

## ทำไมแยกเป็น task

เอกสาร 04 วางระบบเต็ม (sensor 2 node + control 1 node + server) แต่สิ่งที่อยากได้ก่อนคือ
**"สวิตช์ที่สั่งเปิด/ปิดจากมือถือได้ และตั้งเวลาได้"** — มองเป็นสวิตช์เฉยๆ ไม่ผูกกับว่า
ปลายทางเป็นอะไร: วันนี้เสียบปั๊มน้ำ พรุ่งนี้เสียบพัดลม ไฟส่องต้นไม้ หรืออย่างอื่นก็ได้
เส้นนี้จบได้ด้วยของแค่ 3 ชิ้น (ESP32 + relay + load อะไรสักอย่าง)
ไม่ต้องรอ sensor, ไม่ต้องรอฐานข้อมูล, ไม่ต้องรอโรงเรือน

## ขอบเขต

**ทำ:**
- ESP32 + relay = สวิตช์สั่งเปิด/ปิดผ่าน MQTT (relay หลายช่อง = หลายสวิตช์ในตัวเดียว)
- ตั้งเวลา (schedule) เปิด/ปิดอัตโนมัติต่อช่อง
- หน้าเว็บง่ายๆ ไว้กดสั่งและตั้งเวลา

**ไม่ทำ (ยังอยู่ในแผนใหญ่ตามเดิม):**
- sensor ทุกชนิด
- เก็บ Reading ลงฐานข้อมูล
- Rule engine (ดินแห้ง → รดน้ำ)
