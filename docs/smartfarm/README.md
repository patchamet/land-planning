## สถานะโดยรวม (อ่านตรงนี้ก่อน)

**ยังไม่ตัดสินใจ:**
- ขนาดและรูปแบบโรงเรือนจริง
- ปลูกพืชอะไรรอบแรก

**ตัดสินใจแล้ว:**
- เริ่มจากซอฟต์แวร์ก่อนฮาร์ดแวร์ — เพราะเป็นส่วนที่แพงที่สุดถ้าจ้างทำ
- ซอฟต์แวร์ตัวแรกคือ **ระบบบันทึกการทดลอง** ที่กรอกมือได้ ไม่ใช่ dashboard อ่านค่า sensor
- **เก็บข้อมูลในเครื่อง (IndexedDB) + ทำเป็น PWA** — [ADR-0001](adr/0001-data-storage.md)
- ยังไม่แตะ IoT / sensor / hardware จนกว่าจะถึง Phase 3 ใน [00-concept.md](00-concept.md)

**หลักการที่คุมทุกการตัดสินใจในเอกสารชุดนี้:**

> โรงเรือนยังไม่ชัวร์ → ห้าม hardcode อะไรที่ผูกกับโรงเรือน
> ขนาด จำนวนแปลง ชนิดพืช ชนิดค่าที่วัด ต้องเป็น**ข้อมูลที่ผู้ใช้สร้างเอง** ไม่ใช่โครงสร้างในโค้ด

## C4 model — เราใช้ระดับไหน

[C4](https://c4model.com) อธิบายสถาปัตยกรรมเป็น 4 ระดับ ซูมเข้าไปทีละชั้น เหมือน Google Maps

| ระดับ | ตอบคำถาม | เราทำไหม |
|---|---|---|
| **L1 Context** | ระบบคืออะไร ใครใช้ ต่อกับอะไรข้างนอก | ✅ [01](01-context.md) |
| **L2 Container** | แยกเป็นกี่ส่วนที่รันแยกกัน เก็บข้อมูลที่ไหน | ✅ [02](02-container.md) |
| **L3 Component** | ในแต่ละส่วนมีโมดูลอะไร | ⏸️ รอจนโค้ดเริ่มมีรูปร่าง — เขียนตอนนี้คือเดา |
| **L4 Code** | class / function | ❌ ไม่ทำ ปล่อยให้โค้ดอธิบายตัวเอง |

**เหตุผลที่ใช้ C4 กับโปรเจกต์เล็กขนาดนี้** ไม่ใช่เพราะระบบซับซ้อน (มันไม่ซับซ้อนเลย) แต่เพราะ L1/L2 บังคับให้ตอบคำถามเดียวที่สำคัญที่สุดของโปรเจกต์นี้ได้ตั้งแต่ยังไม่เขียนโค้ด:

> **"ตอนที่ sensor เข้ามาในอีก 1 ปี ต้องรื้ออะไรบ้าง"**

ถ้าตอบว่า "ไม่ต้องรื้ออะไรเลย นอกจากเพิ่มกล่องใหม่ 1 กล่อง" แปลว่าออกแบบถูก

## ธรรมเนียมการเขียนเอกสารในโฟลเดอร์นี้

- **ชื่อไฟล์ภาษาอังกฤษ เนื้อหาภาษาไทย** (ตามที่ใช้ทั้ง repo)
- **ใส่เลขนำหน้า** ตามลำดับที่ควรอ่าน
- **ทุกไฟล์มีสถานะบนสุด** — 🟡 ร่าง / 🟢 ตกลงแล้ว / ⚫ ยกเลิกแล้ว
- **ไดอะแกรมใช้ Mermaid** ในไฟล์ .md (แสดงผลได้บน GitHub และ editor ส่วนใหญ่) ไม่ทำเป็นรูปแยก เพราะรูปจะไม่ถูกอัปเดตตามโค้ด
- **การตัดสินใจที่กลับยาก → เขียนเป็น ADR** ไม่ฝังไว้ในเอกสารอื่น เพราะอีก 6 เดือนจะจำไม่ได้ว่าทำไมถึงเลือกแบบนั้น
- **ADR ที่ถูกล้มทีหลัง ไม่ลบ** — เปลี่ยนสถานะเป็น "ถูกแทนที่โดย ADR-XXXX" ประวัติการตัดสินใจมีค่าพอๆ กับตัวการตัดสินใจ
