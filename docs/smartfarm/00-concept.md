# แนวคิดโรงเรือนทดลอง Smart Farm — หลังแรก

> เอกสารขั้นออกแบบแนวคิด (concept design) — ยังไม่แตะเทคโนโลยี IoT / sensor / software
> พื้นที่: นครปฐม ~2 ไร่ | เป้าหมายเฟสแรก: โรงเรือนทดลอง 1 หลัง
> สถานะ: ร่างเพื่อใช้ตัดสินใจ ยังไม่ใช่แบบก่อสร้าง

---

## 0. บริบทของนครปฐมที่กำหนดทุกอย่างในเอกสารนี้

ก่อนตอบเรื่องขนาดหรือระบบ ต้องเข้าใจสภาพพื้นที่ก่อน เพราะมันคือเหตุผลเบื้องหลังคำแนะนำทุกข้อ

| ปัจจัย | สภาพจริง | ผลต่อการออกแบบ |
|---|---|---|
| ฤดูร้อน (มี.ค.–พ.ค.) | 35–40°C กลางวัน | โรงเรือนปิดทึบจะร้อน **กว่า** ข้างนอก 8–12°C — ความสูงและช่องลมคือเรื่องคอขวด |
| ฤดูฝน (พ.ค.–ต.ค.) | ฝนชุก ความชื้น 80–95% | ปัญหาหลักคือโรคเชื้อรา ไม่ใช่ความร้อน |
| ฤดูหนาว (พ.ย.–ก.พ.) | 18–30°C | **ช่วงทองของการปลูก** — ควรวางแผนให้รอบทดลองสำคัญตกในช่วงนี้ |
| ภูมิประเทศ | ที่ราบลุ่มแม่น้ำ ดินเหนียว | น้ำขังง่าย → ต้องยกพื้นแปลง + ทำระบบระบายน้ำรอบโรงเรือน |
| น้ำใต้ดิน | หลายจุดกร่อย/เหล็กสูง | **ต้องส่งตรวจคุณภาพน้ำก่อนออกแบบระบบใดๆ** |

**ข้อสรุปที่ต้องยอมรับตั้งแต่ต้น:** โรงเรือนในเขตร้อนชื้นไม่ได้ทำให้ "เย็นลง" มันทำให้ "ควบคุมได้" — กันฝน กันแมลง คุมน้ำ คุมปุ๋ย ส่วนความร้อนทำได้แค่ *ไม่ให้ร้อนกว่าข้างนอก* ใครที่คาดหวังว่ามีโรงเรือนแล้วจะปลูกผักเมืองหนาวได้ในเดือนเมษายน จะผิดหวัง

## 1. ขนาดโรงเรือนทดลอง

### สรุป: **6 × 12 เมตร (72 ตร.ม.)** — หรือ 6 × 15 ม. ถ้าอยากเผื่อ

| ขนาด | ประเมิน | เหตุผล |
|---|---|---|
| 3×6 = 18 ตร.ม. | **เล็กเกินไป** | ปลูกได้ แต่ทดลองไม่ได้ — ไม่มีพื้นที่พอทำ "แปลงควบคุม + แปลงทดลอง + ทำซ้ำ" ผลที่ได้จะเป็นแค่ความรู้สึก ไม่ใช่ข้อมูล |
| 6×8 = 48 ตร.ม. | เล็กแต่พอไหว | ทำได้ 2 treatment ไม่มีที่ทำซ้ำ เหมาะถ้างบจำกัดจริงๆ |
| **6×12 = 72 ตร.ม.** | **เหมาะที่สุด** | ดูรายละเอียดด้านล่าง |
| 6×20 = 120 ตร.ม. | เริ่มเกินตัว | ค่าก่อสร้างโดด และงานดูแลเกินคนเดียวช่วงเก็บเกี่ยว |
| 2 หลังพร้อมกัน | **ใหญ่เกินไปแน่นอน** | ถ้าออกแบบผิด ผิดสองเท่า ควรผิดให้ถูกก่อนหนึ่งหลัง |

### ทำไม 6×12

1. **กว้าง 6 ม. คือขนาดโครงมาตรฐานในไทย** — หาช่าง หาอะไหล่ หาพลาสติกคลุมตามขนาดได้ทุกร้าน ราคาต่อ ตร.ม. ถูกที่สุด ถ้าออกแบบขนาดแปลกจะแพงขึ้นทันทีโดยไม่ได้อะไรกลับมา
2. **หักทางเดินและพื้นที่บริการแล้วเหลือปลูกจริง ~45–50 ตร.ม.** แบ่งเป็น 4 แปลงย่อยได้สบาย ซึ่งคือ **จำนวนขั้นต่ำที่ทำให้ผลการทดลองเชื่อถือได้** (2 แบบ × ทำซ้ำ 2 ครั้ง) — 2 แปลงไม่พอ เพราะถ้าผลต่างกันจะแยกไม่ออกว่าเพราะวิธีปลูกหรือเพราะตำแหน่งในโรงเรือน
3. **คนเดียวดูแลไหว** — ช่วงปกติราว 30–60 นาที/วัน ช่วงเก็บเกี่ยวหนักขึ้นแต่ยังไม่ถึงขั้นต้องจ้างคน
4. **ยาว 12 ม. ทำให้เกิดลมพัดผ่านตามแนวยาวได้จริง** — โรงเรือนสั้นและกว้างระบายอากาศแย่กว่า

### เรื่องที่สำคัญกว่าพื้นที่: **ความสูง**

นี่คือสาเหตุความล้มเหลวอันดับหนึ่งของโรงเรือนในไทย — สร้างเตี้ยเพราะประหยัด แล้วร้อนจนปลูกอะไรไม่ได้หน้าร้อน

- **ชายคา (ผนังข้าง) สูงอย่างน้อย 2.5–3.0 ม.**
- **สันหลังคาสูง 4.0–4.5 ม.**
- เหตุผล: อากาศร้อนลอยขึ้น ต้องมี "ปริมาตรอากาศเหนือหัวพืช" ให้ความร้อนไปกองและระบายออกทางสันหลังคา ถ้าเพดานเตี้ย ความร้อนจะกองอยู่ที่ระดับใบพืชพอดี

**เพิ่มความสูง 1 เมตร แพงขึ้นไม่กี่เปอร์เซ็นต์ แต่เปลี่ยนผลลัพธ์ทั้งปี** — ถ้าต้องเลือกระหว่างยาวขึ้นกับสูงขึ้น ให้เลือกสูง

### วางตำแหน่งบนที่ 2 ไร่

- **ล็อกผังไว้ตั้งแต่วันแรกว่าหลังที่ 2, 3, 4 จะอยู่ตรงไหน** เว้นระยะระหว่างหลัง 4–6 ม. (ไม่ใช่แค่ทางเดิน — เว้นน้อยกว่านี้หลังหน้าจะบังลมหลังหลัง)
- หลีกเลี่ยงเงาไม้ใหญ่/อาคารในช่วงเช้า (แสงเช้ามีค่าที่สุดสำหรับพืช)
- วางให้ช่องระบายอากาศรับลมประจำถิ่น (ไทยกลาง: ลมใต้-ตะวันตกเฉียงใต้หน้าร้อน, ลมเหนือ-ตะวันออกเฉียงเหนือหน้าหนาว)
- อยู่ใกล้แหล่งน้ำและไฟฟ้า และ **รถเข้าถึงได้** (ตอนขนวัสดุปลูกและตอนขนผลผลิตออก)
- ไม่ใช่จุดต่ำสุดของที่ดิน

## 2. ระบบที่โรงเรือนควรมี

### 🔴 ต้องมีตั้งแต่แรก — ไม่มีแล้วทดลองไม่ได้ หรือแก้ทีหลังแพงมาก

| ระบบ | รายละเอียด | ทำไมต้องแรก |
|---|---|---|
| **โครงสร้าง + หลังคากันฝน** | โครงเหล็กชุบ, พลาสติก UV 150 micron | ฝนคือศัตรูอันดับ 1 ในไทย ไม่ใช่ความร้อน |
| **มุ้งกันแมลง 40–50 mesh รอบด้าน** | ปิดทุกช่องเปิด | กันเพลี้ยไฟ/แมลงหวี่ขาว ซึ่งเป็น *พาหะไวรัส* — ไวรัสไม่มียารักษา ต้องกันอย่างเดียว |
| **ระบายอากาศธรรมชาติ** | ช่องระบายสันหลังคา (ridge vent) + ผนังข้างเปิดได้ | **แก้ทีหลังคือรื้อหลังคา** ต้องมีตั้งแต่วันแรก |
| **ระบบน้ำ + แยกวาล์วรายแปลง** | แหล่งน้ำ → ถังพัก → ปั๊ม → กรอง → วาล์ว 4 ตัว → น้ำหยด | แยกวาล์วราคาไม่กี่ร้อยบาท แต่คือสิ่งที่ทำให้ "ทดลอง" ต่างจาก "ปลูก" |
| **ยกพื้นแปลง + ระบายน้ำรอบโรงเรือน** | ยกแปลง 20–40 ซม., ร่องระบายรอบนอก | ดินเหนียวนครปฐม น้ำขังคือรากเน่า |
| **แปลงปลูกแบบถอด/ย้ายได้** | กระบะ ถุงปลูก หรือกระถางบนขาตั้ง — **ห้ามก่อปูนตาย** | ถ้าก่อปูน = ล็อกรูปแบบการทดลองไปตลอดชีวิตโรงเรือน |
| **พรางแสงแบบดึงเข้า-ออกได้** | สแลน 50% บนราง/รอก | พรางถาวรจะทำร้ายพืชในหน้าฝนที่แดดน้อยอยู่แล้ว |
| **ระบบบันทึก** | สมุด/ฟอร์ม + ตาชั่ง + เทอร์โมมิเตอร์ max-min แบบไม่ใช้ไฟ | เป็น "ระบบ" ที่คนลืมที่สุด แต่มันคือทั้งหมดของคำว่าโรงเรือน**ทดลอง** |
| **ไฟฟ้า + จุดน้ำล้าง** | ปลั๊กกระจายทุกมุม เผื่อไว้ 2 เท่า | เดินสายทีหลังในโรงเรือนที่ปลูกแล้วคือฝันร้าย |

### 🟡 ควรมี — ปีแรกถึงปีที่สอง

- **ระบบลดความร้อน** — พัดลมดูดอากาศปลายโรงเรือน หรือระบบพ่นหมอกช่วงบ่าย (เตรียมจุดติดตั้งและไฟไว้ก่อน ค่อยซื้อทีหลัง)
- **ระบบผสมปุ๋ยแยกจากน้ำ** — ถังปุ๋ย A/B + ตัวดูดปุ๋ย เพื่อ "เปลี่ยนสูตรได้" ไม่ใช่ผสมในถังใหญ่ถังเดียว
- **โซนต้นกล้าแยกส่วน** มีมุ้งของตัวเอง — ต้นกล้าคือช่องทางหลักที่โรคและแมลงเข้าโรงเรือน
- **ค้าง/ตาข่าย + จุดแขวนจากโครงหลังคา** — แต่ **โครงหลังคาต้องออกแบบให้รับน้ำหนักแขวน 15–20 กก./จุด ตั้งแต่แรก** (นี่เป็นข้อ "ต้องมีตั้งแต่แรก" ซ่อนอยู่ในข้อ "ควรมี")
- **ประตูสองชั้น / ห้องกันแมลงหน้าประตู** 1.5×1.5 ม. + อ่างจุ่มเท้า
- **โต๊ะทำงาน + จุดคัดบรรจุ + ที่เก็บอุปกรณ์**
- **รางรองน้ำทิ้งใต้แปลง** — เก็บน้ำที่ไหลผ่านรากออกมาได้ = วัดได้ว่าให้ปุ๋ยเกินหรือขาด

### ⚪ มีทีหลังก็ได้ — อย่าเพิ่งลงทุน

- **ระบบเซนเซอร์/ควบคุมอัตโนมัติ** ← ในมุมของ "การทำฟาร์ม" อันนี้อยู่ท้ายสุด (ดูข้อ 7 ว่าทำไม และมันควรเข้ามาเมื่อไร)
- Evaporative cooling pad & fan — แพง ใช้น้ำมาก และในความชื้นสูงแบบไทยได้ผลจำกัดกว่าที่โฆษณา
- ไฟเสริมแสงปลูกพืช — ไทยแดดเกินพอ ไม่จำเป็นเลย
- ระบบเติม CO₂ — เกินความจำเป็นสำหรับโรงเรือนที่ระบายอากาศแบบเปิด
- ไฮโดรโปนิกส์เต็มระบบ (NFT/DFT) — เริ่มจากวัสดุปลูกในถุง/กระถางก่อน ล้มเหลวถูกกว่ามาก
- โซลาร์เซลล์
- กล้องวงจรปิด — เฟสแรกใช้รั้วกับกุญแจพอ
- โรงเรือนหลังที่ 2

## 3. การจัดการสภาพแวดล้อม — แต่ละอย่างมีผลอย่างไร

### 🌡️ อุณหภูมิ

**ผลต่อพืช:** พืชผลส่วนใหญ่หยุดติดผลเมื่อเกิน 32–35°C (ละอองเกสรตายหรือเป็นหมัน) และ **อุณหภูมิกลางคืนที่สูงเกิน 24°C จะทำให้พืชหายใจเผาผลาญน้ำตาลที่สะสมมาทั้งวันทิ้ง** — เป็นเหตุผลว่าทำไมผลไม้ในไทยหน้าร้อนถึงไม่หวาน

**โรงเรือนช่วยอะไรได้:** ตัดแดดตรง + พาความร้อนออกทางสันหลังคา
**โรงเรือนช่วยไม่ได้:** ทำให้เย็นกว่าอากาศภายนอก (ยกเว้นลงทุนระบบทำความเย็นซึ่งไม่คุ้มสำหรับหลังแรก)
**ตัวแปรที่คุมได้จริง:** ความสูง + ขนาดช่องระบายอากาศ + การพรางแสง
**เป้าหมายที่สมจริง:** ในโรงเรือนไม่ร้อนกว่านอกโรงเรือนเกิน 3–4°C ตอนบ่าย

### 💧 ความชื้น

**ผลต่อพืช:** ตัวชี้วัดที่แท้จริงไม่ใช่ %RH แต่คือ "แรงดึงน้ำในอากาศ" (VPD)
- **ชื้นเกิน (>85%)** → พืชคายน้ำไม่ได้ → **ดูดแคลเซียมขึ้นไม่ถึงผล → ก้นผลเน่า** + เชื้อราระบาด
- **แห้งเกิน (<40%)** → ปากใบปิด → หยุดสังเคราะห์แสงทั้งที่แดดจ้า

**ปัญหาของไทยคือชื้นเกิน** โดยเฉพาะกลางคืนและฤดูฝน
**วิธีจัดการ:** ระบายอากาศตอนเช้าตรู่ (ไล่ความชื้นที่สะสมทั้งคืน), ไม่รดน้ำตอนเย็น, ตัดแต่งใบล่างให้ลมผ่านโคนต้น

### ☀️ แสง

**ในไทย แสงไม่ใช่ปัจจัยจำกัด — มันเกินพอ** ปัญหาคือ:
- แดดแรงเกินทำให้ใบไหม้ ผลไหม้ (โดยเฉพาะพืชที่ยกผลขึ้นค้าง)
- แสงพาความร้อนเข้ามาด้วย

**ประเด็นสำคัญ: พรางแสงต้องปรับได้** ถ้าตรึงสแลน 50% ไว้ถาวร พอถึงฤดูฝนที่เมฆบังอยู่แล้ว พืชจะได้แสงไม่พอ → ต้นยืด อ่อนแอ ล้มโรคง่าย

### 🌬️ การระบายอากาศ — **หัวใจของโรงเรือนเขตร้อน**

ทำ 3 หน้าที่พร้อมกัน:
1. ไล่ความร้อน
2. ลดความชื้น (ป้องกันเชื้อรา)
3. **เติม CO₂** ← ข้อที่คนมองข้ามที่สุด ในโรงเรือนปิดสนิท พืชจะดูด CO₂ จนหมดภายใน 1–2 ชั่วโมงหลังพระอาทิตย์ขึ้น แล้ว**หยุดโตทั้งที่แดดจ้าและน้ำปุ๋ยพร้อม**

**หลักออกแบบ:** พื้นที่ช่องเปิดรวม ≥ 20–25% ของพื้นที่พื้น และควรใช้การระบายแบบธรรมชาติเป็นหลัก (ลมเข้าข้าง-ออกสันหลังคา) เพราะไม่มีค่าไฟและไม่พังตอนไฟดับ

### 🌧️ ฝน — เหตุผลอันดับหนึ่งที่ควรมีโรงเรือนในไทย

ฝนสร้างปัญหา 4 ทาง: กระเด็นดินติดใบ (พาเชื้อโรคขึ้นต้น), ชะปุ๋ยหาย, ทำผลแตก (มะเขือเทศ/แตง/เมล่อน), กระแทกดอกร่วง

**โรงเรือนแก้ได้ ~90%** แต่ระวัง **"ฝนสาดข้าง"** — โรงเรือนที่เปิดผนังข้างเพื่อระบายอากาศ จะโดนฝนสาดเข้าเป็นแถบกว้าง 1–2 ม. ต้องแก้ด้วยชายคายื่นหรือม่านข้างที่ปิดได้ตอนฝนตก

### 🐛 แมลง

**มุ้ง 40–50 mesh กันได้:** เพลี้ยไฟ แมลงหวี่ขาว หนอนผีเสื้อ แมลงวันทอง
**กันไม่ได้:** ไรแดง (ตัวเล็กกว่ารูมุ้ง) และทุกอย่างที่ **ติดมากับต้นกล้า เสื้อผ้า หรือรองเท้าคน**

**Trade-off ที่ต้องรู้:** มุ้งถี่ทำให้ลมผ่านลดลง 30–50% → ยิ่งกันแมลงดี ยิ่งร้อนและชื้น ต้องชดเชยด้วยพื้นที่ช่องเปิดที่มากขึ้น **ไม่ใช่ mesh ยิ่งถี่ยิ่งดี**

### 🍄 เชื้อรา

**ตัวจุดชนวนมี 2 อย่างเสมอ:** ใบเปียกนานเกิน 4–6 ชั่วโมง + อากาศนิ่ง

โรงเรือนช่วยได้มาก เพราะควบคุมได้ว่า "ใบจะไม่เปียก" — ให้น้ำที่โคนต้นด้วยน้ำหยด ไม่ใช่สปริงเกอร์บนใบ

**เพิ่มเติม — โรคทางดิน:** ถ้าปลูกลงดินเดิมซ้ำๆ ในโรงเรือน เชื้อโรคทางดินจะสะสมจนปลูกไม่ได้ภายใน 2–3 ปี นี่คือเหตุผลที่ **ควรใช้แปลงยกพื้นหรือวัสดุปลูกที่เปลี่ยนได้** ตั้งแต่แรก

## 4. พืชสำหรับการทดลอง — จัดกลุ่มตามบทบาท

ไม่ได้เลือกให้ แต่จัดกลุ่มตามว่าแต่ละชนิด "ใช้ทดลองอะไร"

### กลุ่ม A — พืชสอนระบบ (รอบสั้น ใช้พิสูจน์ว่าโรงเรือนทำงานไหม)

| พืช | รอบ | ความยาก | มูลค่า | บทบาทในการทดลอง |
|---|---|---|---|---|
| **ผักสลัด** (กรีนโอ๊ค/คอส) | 35–45 วัน | ปานกลาง | สูง | **เป็นเครื่องวัดโรงเรือน** — ไวต่อความร้อนมาก เกิน 30°C จะขมและยืด ถ้าปลูกได้สวยแปลว่าคุมอุณหภูมิได้จริง |
| **ผักไทยใบเขียว** (คะน้า/กวางตุ้ง/ผักบุ้ง) | 25–35 วัน | ง่ายมาก | ต่ำ | **แปลงควบคุมที่ไม่มีวันเจ๊ง** — ใช้เทียบและกันไม่ให้โรงเรือนว่าง |
| **โหระพา/กะเพรา** | 30 วัน แล้วเก็บได้เรื่อยๆ | ง่าย | ปานกลาง | ทนร้อน เก็บได้ยาว เหมาะเป็นแปลงยืนพื้น |

### กลุ่ม B — พืชที่ "คุ้มกับการมีโรงเรือน" (โจทย์จริงถ้าจะเป็นธุรกิจ)

| พืช | รอบ | ความยาก | มูลค่า | หมายเหตุ |
|---|---|---|---|---|
| **แตงกวาญี่ปุ่น** | 40–60 วัน | ปานกลาง | ปานกลาง | **"เมล่อนฝึกหัด" ที่ดีที่สุด** — ระบบเหมือนเมล่อนแทบทุกอย่าง (ค้าง แขวน ตัดแต่ง ผสมเกสร) แต่รอบสั้นกว่าครึ่ง พลาดแล้วเริ่มใหม่ได้เร็ว |
| **มะเขือเทศเชอรี่** | 90–120 วัน เก็บยาว | ปานกลาง–ยาก | ดี | สอนเรื่องธาตุอาหารและโรคได้มากที่สุด ปลูกยาวทำให้ทดลองอะไรระหว่างทางได้เยอะ |
| **เมล่อน** | 75–90 วัน | ยาก | สูงมาก | พืชที่คนสร้างโรงเรือนในไทยเพื่อปลูกมากที่สุด — แต่ **ไม่ควรเป็นพืชแรก** พลาดรอบเดียวเสีย 3 เดือน |
| **พริกหวาน** | 100–140 วัน | ยากมาก | สูง | ต้องการอากาศเย็นต่อเนื่อง — ในนครปฐมท้าทายมากช่วงหน้าร้อน เก็บไว้เป็นโจทย์ท้าทายทีหลัง |

### กลุ่ม C — ยังไม่ควรเอามาทดลองในหลังแรก

- **ไม้ผลยืนต้น** — รอบยาวเกินกว่าจะเรียนรู้อะไรได้ใน 2 ปี
- **เห็ด** — ต้องการสภาพ *ตรงข้าม* กับโรงเรือนปลูกพืช (มืด ชื้นสูง ไม่ระบายอากาศ) ต้องแยกโรงเรือน
- **สตรอว์เบอร์รี** — ต้องการอากาศเย็นยาวนาน ไม่เหมาะกับนครปฐม
- **กัญชา/กัญชง** — เป็นคนละโจทย์ทั้งด้านกฎหมาย เงินทุน และความปลอดภัย

### ⚠️ ข้อที่ต้องรู้ก่อนเลือกพืช

**การกางมุ้งกันแมลง = ไม่มีแมลงผสมเกสร** พืชตระกูลแตง (เมล่อน แตงกวา ฟักทอง) ต้อง **ผสมเกสรด้วยมือ** ทุกดอก ทุกเช้า ในกรอบเวลาไม่กี่ชั่วโมง นี่คือภาระแรงงานที่คนวางแผนมักลืม — ถ้าไม่มีเวลาไปโรงเรือนทุกเช้า ให้ตัดกลุ่มนี้ออกไปก่อน

**คำแนะนำสำหรับรอบแรก:** ปลูกกลุ่ม A ให้ครบก่อน 1–2 รอบ (ให้ระบบและตัวเองผ่านการทดสอบด้วยความเสี่ยงต่ำ) แล้วค่อยเข้ากลุ่ม B โดยเริ่มจากแตงกวาญี่ปุ่นหรือมะเขือเทศ ไม่ใช่เมล่อน

## 5. การแบ่งพื้นที่ภายใน (6 × 12 ม. = 72 ตร.ม.)

```
        ← 6.0 ม. →
   ┌─────────────────────┐
   │  ห้องกันแมลง 1.5×1.5│  ← ประตูสองชั้น + อ่างจุ่มเท้า
   ├──────────┬──────────┤
   │  โซนกล้า │ โต๊ะ/ชั่ง│  ~6 ตร.ม.  (ชั้นวาง 2 ชั้น)
   ├──────────┴──────────┤
   │ แปลง A1  │ แปลง B1 │  1.2 × 5.0 ม. ต่อแปลง
   │          │         │
   │ ─ ทางเดินกลาง 1.0 ม.─│  ← เข็นรถเข็นได้
   │          │         │        12 ม.
   │ แปลง A2  │ แปลง B2 │
   │          │         │
   ├──────────┴──────────┤
   │ พื้นที่ยืดหยุ่น ~15 ตร.ม.│  ← จงใจปล่อยว่าง
   ├─────────────────────┤
   │ โซนน้ำ/ปุ๋ย (ติดผนัง)│  ~5 ตร.ม. มีหลังคาแยก
   └─────────────────────┘
```

| พื้นที่ | ขนาด | หมายเหตุ |
|---|---|---|
| แปลงปลูก 4 แปลง | 1.2 × 5.0 ม. × 4 ≈ 24 ตร.ม. | **กว้าง 1.2 ม. คือระยะที่เอื้อมถึงกลางแปลงได้จากทั้งสองข้างโดยไม่ต้องเหยียบ** |
| ทางเดินกลาง | 1.0 × 12 ม. = 12 ตร.ม. | อย่าแคบกว่า 0.8 ม. — ต้องเข็นรถเข็นและถือถังผ่านได้ |
| โซนต้นกล้า + โต๊ะทำงาน | ~6 ตร.ม. | ควรอยู่ปลายด้านที่แดดเช้าถึง |
| โซนน้ำ/ปุ๋ย | ~5 ตร.ม. | **ควรอยู่ติดผนังหรือนอกโรงเรือน** เพราะปุ๋ยไม่ควรอยู่ในที่ชื้น |
| ห้องกันแมลง | 2.25 ตร.ม. | ไม่ใช่ของฟุ่มเฟือย — เป็นสิ่งที่ทำให้มุ้งมีความหมาย |
| **พื้นที่ยืดหยุ่น** | **~15 ตร.ม. (20%)** | ดูด้านล่าง |

### เรื่องพื้นที่ยืดหยุ่น — ข้อที่คนพลาดกันมากที่สุด

ทุกคนอยากใช้พื้นที่ให้เต็ม แล้วพอถึงเวลาจะทดลองอะไรใหม่ก็ไม่มีที่ทำ ต้องรอให้รอบเดิมจบก่อน = **การทดลองช้าลง 3 เท่า**

**ควรเหลือว่างไว้ 20–25%** เพื่อ:
- ตั้งการทดลองรอบถัดไปทับซ้อนกับรอบปัจจุบัน (ไม่ต้องรอ)
- ลองรูปแบบปลูกใหม่ (ปลูกแขวน ปลูกซ้อนชั้น) โดยไม่รื้อของเดิม
- กักตัวต้นที่เป็นโรค
- พื้นที่ทำงาน/กองวัสดุตอนเปลี่ยนรอบ

## 6. ออกแบบให้ "เปลี่ยนโจทย์ทดลองได้ง่าย"

หลักการเดียว: **ทุกอย่างต้องเป็นโมดูล ถอดได้ แยกวาล์วได้ และมีชื่อพิกัดถาวร**

| # | สิ่งที่ต้องทำ | ทำให้ทดลองอะไรได้ | ถ้าไม่ทำตั้งแต่แรก |
|---|---|---|---|
| 1 | แปลงเป็นกระบะ/ถุง/กระถางบนขาตั้ง ไม่ก่อปูน | เปลี่ยนผังทั้งโรงเรือนได้ในครึ่งวัน | ล็อกรูปแบบตลอดชีวิตโรงเรือน |
| 2 | **น้ำแยกวาล์วอิสระทุกแปลง (≥4 โซน)** | ทดลองปริมาณน้ำ/ความถี่/สูตรปุ๋ยต่างกันในโรงเรือนเดียว | ต้องรื้อระบบน้ำทั้งเส้น |
| 3 | **ตั้งชื่อพิกัดถาวร A1–A2, B1–B2 ทาสี/ติดป้ายจริงบนโครงสร้าง** | ทุกบันทึก ทุกรูปถ่าย ทุกค่าที่วัด อ้างพิกัดเดียวกันตลอดไป | ข้อมูลย้อนหลังจะอ่านไม่รู้เรื่อง |
| 4 | ม่านพลาสติกใสแบ่งครึ่งโรงเรือนได้ | สร้าง 2 สภาพอากาศในหลังเดียว → ทดลองอุณหภูมิ/ความชื้นแบบเทียบคู่ | ต้องมีโรงเรือน 2 หลังถึงจะเทียบได้ |
| 5 | โครงหลังคารับน้ำหนักแขวน 15–20 กก./จุด | เปลี่ยนจากปลูกพื้น → ปลูกค้าง/แขวน/ซ้อนชั้น | เสริมโครงทีหลัง = รื้อ |
| 6 | รางรองน้ำทิ้งใต้แปลง | วัดน้ำเข้า–ออกได้ → ทดลองเรื่องปุ๋ยได้จริง ไม่ใช่เดา | ทดลองเรื่องปุ๋ยได้แค่ระดับ "รู้สึกว่าดีขึ้น" |
| 7 | ไฟฟ้า + จุดต่อน้ำ เผื่อ 2 เท่า กระจายทุกมุม | เพิ่มอุปกรณ์ทีหลังได้โดยไม่เดินสายใหม่ | เดินสายในโรงเรือนที่ปลูกแล้ว = ฝันร้าย |

### กฎการทดลองที่กำหนดการออกแบบข้างบน

1. **เปลี่ยนทีละ 1 ตัวแปร** — ถ้าเปลี่ยนน้ำและปุ๋ยพร้อมกัน แล้วผลดีขึ้น จะไม่มีวันรู้ว่าเพราะอะไร
2. **มีแปลงควบคุมเสมอ** — แปลงที่ทำแบบเดิมไว้เทียบ
3. **ทำอย่างน้อย 2 ซ้ำ** — เพราะตำแหน่งในโรงเรือนเองก็มีผล (แปลงใกล้ประตูร้อนกว่า)

← **นี่คือเหตุผลทางคณิตศาสตร์ที่ต้องมี 4 แปลง ไม่ใช่ 2** และเป็นที่มาของขนาด 6×12 ในข้อ 1

### ตัวอย่างว่าโรงเรือนหลังเดียวนี้รองรับ 5 การทดลองได้อย่างไร

| รอบ | โจทย์ | ทำอย่างไรโดยไม่รื้ออะไร |
|---|---|---|
| 1 | เรื่องน้ำ | A1,A2 = ให้น้ำสูตรเดิม / B1,B2 = ความถี่ต่างกัน (แค่ตั้งวาล์ว) |
| 2 | เรื่องอุณหภูมิ | ปิดม่านแบ่งครึ่ง — ครึ่งหนึ่งพราง 50% อีกครึ่งไม่พราง |
| 3 | เปรียบเทียบพืช | 4 แปลง 4 ชนิด เงื่อนไขเหมือนกันหมด |
| 4 | วิธีปลูก | 2 แปลงลงวัสดุปลูกพื้น / 2 แปลงยกค้างแขวน (ใช้จุดแขวนที่เตรียมไว้) |
| 5 | เพิ่มผลผลิต | เอาชุดที่ชนะจากรอบ 1–4 มารวมกัน แล้วเทียบกับวิธีเดิม |

## 7. Roadmap และ "ต้องพิสูจน์อะไรก่อนไปต่อ"

### Phase 1 — สร้างโรงเรือนแบบง่าย (เดือน 1–3)

ทำ: โครงสร้าง หลังคา มุ้ง ช่องระบายอากาศ ระบบน้ำแยกวาล์ว ยกแปลง ระบายน้ำรอบนอก ป้ายพิกัด

**ต้องพิสูจน์ให้ได้ก่อนไป Phase 2:**
- ✅ ในโรงเรือนตอนบ่ายไม่ร้อนกว่านอกโรงเรือนเกิน 3–4°C (วัดจริง 7 วันติด)
- ✅ ฝนหนัก 1 ครั้งแล้วไม่มีน้ำขัง ไม่มีน้ำสาดเข้าเกิน 0.5 ม.จากผนัง
- ✅ มุ้งไม่มีรอยรั่ว ประตูปิดสนิท
- ✅ **น้ำถึงทุกแปลงในปริมาณเท่ากัน** — ทดสอบด้วยแก้วตวงวางกระจายทั่วแปลง (ข้อนี้ตกกันเยอะ ท่อปลายเส้นมักได้น้ำน้อยกว่า)

### Phase 2 — ปลูกและเก็บข้อมูล (เดือน 4–9)

ทำ: ปลูกกลุ่ม A ให้ครบ 3 รอบ บันทึกทุกอย่างด้วยมือ

**ต้องพิสูจน์ให้ได้ก่อนไป Phase 3:**
- ✅ ปลูกครบ 3 รอบโดยไม่ตายยกแปลง
- ✅ **ย้อนกลับไปอ่านบันทึกเมื่อ 2 เดือนก่อนแล้วเข้าใจว่าเกิดอะไรขึ้น** ← ถ้าอ่านไม่รู้เรื่อง แปลว่าระบบบันทึกยังใช้ไม่ได้ ต้องแก้ก่อน
- ✅ รู้ต้นทุนจริงต่อรอบ (เมล็ด ปุ๋ย ไฟ น้ำ แรงงาน)
- ✅ **ยังทำต่อเนื่องได้โดยไม่หมดไฟ** ← เป็น gate ที่คนตกมากที่สุด ไม่ใช่เรื่องเทคนิค แต่เป็นเรื่องว่าเราไปโรงเรือนทุกวันได้จริงไหม

### Phase 3 — เพิ่มระบบควบคุม (เดือน 10–15)

**ต้องพิสูจน์ให้ได้ก่อนลงทุน:**
- ✅ **ระบุได้จากข้อมูล Phase 2 ว่า "ตัวแปรไหนคือคอขวดจริง"** — ความร้อนตอนบ่าย? ความชื้นกลางคืน? การให้น้ำไม่สม่ำเสมอ?
- ✅ ถ้ายังตอบไม่ได้ → **ห้ามซื้ออุปกรณ์** เพราะจะได้ระบบที่แก้ปัญหาที่ไม่มีอยู่จริง

← **นี่คือจุดที่ software และระบบอัตโนมัติเข้ามาอย่างมีเหตุผล** ไม่ใช่ก่อนหน้านี้

### Phase 4 — ปรับปรุงผลผลิต (เดือน 16–24)

**ต้องพิสูจน์ให้ได้ก่อนไป Phase 5:**
- ✅ **ทำผลผลิตซ้ำได้ 2–3 รอบติดในระดับใกล้เคียงกัน** — ความสม่ำเสมอสำคัญกว่าสถิติสูงสุด (ธุรกิจต้องส่งของได้ทุกสัปดาห์ ไม่ใช่ดีที่สุดครั้งเดียว)
- ✅ มีผู้รับซื้อจริงอย่างน้อย 1 ราย ที่เคยซื้อจริงแล้ว ไม่ใช่แค่บอกว่าสนใจ

### Phase 5 — ตัดสินใจขยาย

**ต้องพิสูจน์:**
- ✅ กำไรต่อ ตร.ม. ต่อปี × พื้นที่ใหม่ คุ้มค่าลงทุนภายในเวลาที่ยอมรับได้
- ✅ **โรงเรือนอยู่ได้ 1 สัปดาห์โดยไม่มีเราไปดู** — ถ้ายังไม่ได้ ขยายไปก็ดูแลไม่ไหว
- ✅ มีแรงงานหรือระบบทดแทนแรงงานพร้อม

## 8. สรุปภาพเดียว

> **ถ้ามีที่ 2 ไร่ แต่เริ่มจากโรงเรือนทดลอง 1 หลัง**

**ขนาด:** 6 × 12 ม. (72 ตร.ม.) ชายคาสูง 2.5–3 ม. สันหลังคา 4–4.5 ม. — เล็กพอที่คนเดียวดูแลไหว ใหญ่พอที่จะมี 4 แปลงสำหรับทำการทดลองที่เชื่อถือได้ วางบนผังที่ล็อกตำแหน่งหลังที่ 2–4 ไว้แล้ว

**ระบบที่ต้องมีวันแรก:** หลังคากันฝน + มุ้ง 40–50 mesh + ช่องระบายสันหลังคา + ระบบน้ำที่แยกวาล์วได้ 4 โซน + แปลงยกพื้นแบบถอดได้ + พรางแสงปรับได้ + ระบบบันทึก

**หลักออกแบบเพื่อต่อยอด:** ทุกอย่างถอดได้ แยกวาล์วได้ มีชื่อพิกัดถาวร โครงหลังคารับน้ำหนักแขวนได้ ไฟและน้ำเผื่อไว้ 2 เท่า และ **เหลือพื้นที่ว่างไว้ 20%**

**เส้นทาง:** พิสูจน์ว่าโรงเรือนทำงาน → พิสูจน์ว่าเราทำต่อเนื่องได้ → หาคอขวดจากข้อมูลจริง → แก้เฉพาะคอขวดนั้น → ทำซ้ำได้สม่ำเสมอ → ค่อยขยาย

**สิ่งที่ทำให้ต่อยอดเป็นธุรกิจได้ ไม่ใช่ขนาดโรงเรือน แต่คือ:** โรงเรือนหลังนี้ต้องผลิต *ความรู้ที่วัดได้* ออกมาให้ได้ ไม่ใช่แค่ผลผลิต เพราะสิ่งที่จะขยายในอนาคตคือ "สูตรที่รู้แล้วว่าได้ผล" ไม่ใช่ "โครงเหล็กอีกหลัง"

## 9. สิ่งที่อาจมองข้าม (เพิ่มเติมนอกเหนือจากที่ถาม)

| ประเด็น | ทำไมสำคัญ |
|---|---|
| **คุณภาพน้ำ ต้องตรวจก่อนทุกอย่าง** | น้ำบาดาลนครปฐมหลายจุดกร่อยหรือเหล็กสูง ปลูกระบบน้ำหมุนเวียนไม่ได้เลย และแก้ยากมากทีหลัง — **ส่งตรวจ EC, pH, ความกระด้าง, เหล็ก ก่อนออกแบบระบบน้ำ** |
| **ระยะทางจากที่พักถึงที่ดิน** | โรงเรือน 72 ตร.ม. ต้องแวะ **ทุกวัน** ไม่ใช่ทุกสุดสัปดาห์ ถ้าไปได้แค่เสาร์-อาทิตย์ ต้องออกแบบใหม่ทั้งหมด (และนี่คือเหตุผลที่ระบบอัตโนมัติมีคุณค่าจริงในเคสนี้) |
| **ต้นทุนแฝงของที่ดินเปล่า** | รั้ว ไฟฟ้าเข้า น้ำเข้า ทางรถเข้า — ต้องมีก่อนมีโรงเรือน คนมักคิดแต่ค่าโรงเรือน |
| **สัดส่วนงบ** | โครงสร้างมักเป็นแค่ 40–50% ของงบทั้งหมด ที่เหลือคือระบบน้ำ วัสดุปลูก เมล็ด ปุ๋ย และของจิปาถะ |
| **ค่าเปลี่ยนพลาสติกคลุมทุก 3–5 ปี** | เป็นต้นทุนซ้ำที่ต้องคิดรวมในการประเมินความคุ้มค่า |
| **ตลาดต้องเริ่มคุยที่ Phase 2 ไม่ใช่ Phase 4** | ปลูกได้ ≠ ขายได้ ถ้ารู้ตั้งแต่ต้นว่าตลาดต้องการขนาด/เกรดแบบไหน จะออกแบบการทดลองได้ตรงเป้ากว่ามาก |
| **ความปลอดภัย** | ที่ดินเปล่าห่างชุมชน อุปกรณ์และปั๊มน้ำหายง่าย — รั้วและกุญแจมาก่อนกล้อง |

## 10. ต่อไปในฝั่ง software

ผูกกับเอกสารนี้อย่างไร (ยังไม่ลงรายละเอียด แค่ระบุจุดเชื่อม):

- **ข้อ 5 (การแบ่งพื้นที่) + ข้อ 6 ข้อย่อย 3 (ชื่อพิกัดถาวร)** → เป็นโครงสร้างข้อมูลหลัก: โรงเรือน → แปลง → รอบปลูก
- **ข้อ 6 (แนวคิดการทดลอง)** → เป็น schema ของ "การทดลอง 1 ครั้ง": แปลงไหน / ทำอะไรต่างกัน / วัดอะไร / ผลเป็นอย่างไร
- **Phase 2 gate ("ย้อนกลับไปอ่านบันทึกแล้วเข้าใจ")** → เป็น requirement ข้อแรกของ software ที่จะสร้าง
- **Phase 3** → จุดที่ sensor และระบบอัตโนมัติเข้ามาแทน "การกรอกมือ" โดยไม่ต้องเปลี่ยน schema

กล่าวคือ software ที่ทำตอนนี้แล้วไม่เสียของ คือ **ระบบบันทึกการทดลอง** ที่กรอกมือได้ก่อน แล้วค่อยต่อ sensor ทีหลัง — ไม่ใช่ dashboard อ่านค่า sensor
